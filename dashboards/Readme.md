# Dashboards

This folder contains Power BI dashboards and related resources for the Retail Sales Forecasting project.

## Files
- **Sales_Forecast.pbix**: The Power BI dashboard file showcasing sales trends, forecasts, and inventory insights.
- **screenshots/**: Contains preview screenshots of the dashboards.

## Dashboard Features
1. **Sales Over Time**:
   - Visualize trends in sales across different time periods.
   - Analyze seasonality and spikes in sales.

2. **Region-Wise Sales**:
   - Compare total sales across different regions.
   - Identify regions with the highest sales performance.

3. **Top Products**:
   - View a ranked list of the top-performing products based on sales.
   - Drill down into individual product performance.

4. **Inventory vs. Sales Analysis**:
   - Explore the relationship between inventory levels and sales performance.

## Usage
1. Open the `Sales_Forecast.pbix` file in Power BI Desktop.
2. Connect to the processed data (`data/processed/sales_data_cleaned.csv`) if prompted.
3. Explore interactive visualizations using filters and slicers.
